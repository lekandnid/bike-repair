# แจ้งซ่อมจักรยาน (เวอร์ชันเว็บสำหรับ iPhone)

หน้าเว็บสำหรับช่าง ทำงานเหมือนแอป Android: งานช่าง / ตรวจรายเดือน / สต็อก / สแกน QR

- ต้องใส่ PIN ช่างก่อนใช้งาน
- ลิงก์ระบบถูกเข้ารหัสด้วย PIN ไว้ในไฟล์ `config.js` จึงไม่มีลิงก์ตัวจริงใน repo
- เปลี่ยน PIN: เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/?setup` แล้วสร้าง config.js ใหม่มาแทนไฟล์เดิม

ไฟล์ `jsQR.min.js` คือไลบรารี jsQR 1.4.0 (Apache License 2.0) https://github.com/cozmo/jsQR
